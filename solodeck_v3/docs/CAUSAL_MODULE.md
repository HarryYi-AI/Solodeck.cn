# Causal Module

SoloDeck separates:

- descriptive patterns
- exploratory causal hypotheses
- quasi-experimental estimates
- validated experimental results

Implemented checks:

- treatment and outcome definition
- candidate confounder selection
- sample size
- overlap
- time ordering
- bootstrap confidence intervals
- regression adjustment
- DID fallback when time fields exist

Candidate causal graphs are exploratory unless backed by experimental evidence or validated statistical evidence.
