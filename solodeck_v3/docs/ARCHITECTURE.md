# Architecture

Important packages:

- `compiler`: TaskSpec and task compiler
- `router`: tool routing, budget routing and tool policy
- `memory`: dataset, schema, graph, trace, failure and utility memory
- `agents`: Planner, Retriever, CausalAnalyst, Executor, Verifier, Explorer and Writer
- `skills`: executable Python skills
- `verification`: artifact, statistical, causal, privacy, trace and output format checks
- `reward`: process reward and agent-wise normalization
- `evolution`: failure analysis, regression task generation and scheduler updates
- `bench`: FARS-style benchmark
- `workflows`: LangGraph StateGraph
